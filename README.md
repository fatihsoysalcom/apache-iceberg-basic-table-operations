# Apache Iceberg Basic Table Operations

This Python example demonstrates basic Apache Iceberg table operations. It shows how to create a table, write data, query data with a predicate, and conceptually explains time travel using a local file-based catalog simulation.

## Language

`python`

## How to Run

1. Ensure you have Python and pip installed.
2. Install the required libraries: pip install pyarrow pyiceberg
3. Run the script: python iceberg_example.py
